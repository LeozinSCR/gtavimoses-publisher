Privacy Policy

Effective date: November 23, 2026

GTAVIMoses Publisher ("the tool") is a personal application run by the operator of the @GTAVIMoses channel on the operator's own computer. It is used only to publish videos to accounts that belong to the operator. This policy explains what data the tool accesses, why, where it is kept, and how access can be revoked.

1. Who is covered

The tool has no public sign-up and no other users. The only accounts it connects to are the operator's own TikTok and YouTube accounts, and only after the operator authorizes access on the official TikTok or Google consent screen.

2. Data accessed through TikTok

With TikTok Login Kit (OAuth 2.0 with PKCE), the tool requests the scopes user.info.basic and video.publish. With that authorization it may receive:

  • OAuth access token, refresh token, their expiry times, the granted scopes and the account's open_id;
  • basic account information returned by the Content Posting API creator query (such as the account's display name, username, avatar URL, the privacy options available for posts and the maximum video duration), used only to choose valid posting settings;
  • identifiers and processing status of the videos the tool uploads (publish_id and post status).

The tool does not read followers, messages, comments, contacts or any content created by other people.

3. Data accessed through YouTube (Google)

The tool uses YouTube API Services (YouTube Data API v3) with Google OAuth 2.0 (with PKCE) and the scopes youtube.upload (to upload videos) and youtube.readonly (to confirm which channel is connected and to read basic statistics of the tool's own uploads). It may receive OAuth tokens, the connected channel's ID and title, and the IDs, status and public statistics (views, likes, comments counts) of videos it uploaded. By using the YouTube features, you are also subject to the YouTube Terms of Service and the Google Privacy Policy.

4. How data is used

Only to upload the operator's own videos, to check that an upload finished, to avoid publishing the same video twice, and to keep a local record of published videos and their basic statistics. Data is not sold, rented, shared with advertisers, or used to build profiles. The tool has no analytics, no advertising and no cookies.

5. Storage and security

  • Tokens are stored as files in a local folder (data/tokens/) on the operator's computer. Publishing records are stored in a local SQLite database on the same computer. There is no server or cloud database operated by GTAVIMoses.
  • Credential and token files are excluded from source control, are never published on this website, and are protected by the operating-system account of the computer where the tool runs. They are not encrypted by the tool itself.
  • All communication with TikTok and Google uses HTTPS. OAuth uses PKCE and a random state value on a local loopback address.

6. Retention

Tokens are kept until they expire, are revoked, or are deleted by the operator. Local publishing records are kept while the channel is active and can be deleted at any time by the operator.

7. Revoking access and deleting data

  • TikTok: remove "GTAVIMoses Publisher" from the authorized apps in the TikTok app settings (security and permissions section for apps and services). Revoked tokens stop working immediately.
  • Google/YouTube: remove access at myaccount.google.com/permissions.
  • Local data: deleting the files in data/tokens/ removes the stored tokens; the operator can also delete the local publishing database. Requests can be sent through the contact below.

8. Website

This website is a static page hosted on GitHub Pages. It has no forms, cookies or analytics. GitHub may process technical data such as IP addresses when serving the page, as described in the GitHub Privacy Statement.

9. Children

The tool is not directed to children and does not knowingly process data of anyone other than the operator.

10. Changes and contact

Changes to this policy are published on this page with a new effective date. Contact: open an issue at github.com/LeozinSCR/gtavimoses-publisher/issues.
