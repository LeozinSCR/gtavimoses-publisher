Short GTA videos, published to our own channels.

GTAVIMoses Publisher is a personal content tool operated by the creator of @GTAVIMoses. It prepares short vertical videos about the Grand Theft Auto games and, after the operator reviews them, uploads them to the operator's own TikTok and YouTube accounts using the platforms' official APIs.

How it works

1. Create

Videos are produced on the operator's own computer: script checked against public sources, narration, captions and editing.

2. Review

Nothing is posted automatically by default. The operator reviews each video and approves it before upload.

3. Publish

Approved videos are sent through the TikTok Content Posting API and the YouTube Data API v3, after the account owner authorizes access with OAuth.

Who uses it

Only the operator of @GTAVIMoses. The tool is not offered to the public, has no user registration, and does not access anyone else's accounts. It connects only to accounts that their owner explicitly authorizes through the official TikTok and Google sign-in screens.
